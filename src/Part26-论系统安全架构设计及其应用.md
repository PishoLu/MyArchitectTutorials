## 正文

我就职于一家为材料行业提供数字化服务软件的公司，我司与多个钢厂、材料研究室、高校合作多年。近年来，为应对材料科研人员在文献调研、数据挖掘和科研思路获取方面的痛点，结合最新的 AI 技术发展迅猛的势头，我司决心给行业科研人员提供一便捷、智能化的科研论文智能解析平台，该平台不仅收容了过去 50 年内的材料行业相关论文，通过 AI 对论文进行解析、分类、提取关键词，同时也支持用户对在线上传的文件进行文字提取、AI 解析、AI 知识库交互。该项目由用户与学者管理、文献管理、文献 AI 解析、智能算法推荐等多个子系统组成，在历经 8 个月的设计开发后，在 2023 年底上线，至今运行与维护长达两年，得到了行业内各人士的一致好评。我作为系统架构设计师，负责了该系统的设计与研发。

系统安全架构设计的核心要素既基础设施安全、网络安全、访问与控制安全、应用安全、数据安全。安全架构设计并非孤立的部署几个安全产品，而是一个贯穿系统生命周期、多维度、纵深防御的体系化工程。

为保障基础设施安全，需要加固应用本身及其运行环境，抵御外部攻击和内部威胁。主要通过一、混合云安全策略，严格执行“敏感数据不出私域”的原则。用户数据、文献元数据存于私有云，将计算密集型的 AI 解析、模型训练任务通过安全的专线弹性调度至公有云。二、容器与编排安全，基于 Kubernetes 的安全最佳实践，使用命名空间进行逻辑隔离，配置网络策略控制 Pod 间通信，运用安全上下文限制容器的权限，并定期对镜像进行漏洞扫描。三、通过 K8s Network Policies 实现微服务间的零信任网络，默认拒绝所有流量，仅开放必要的服务间通信端口。

网络安全，采用如下措施：一、微服务安全，利用服务网格与服务间的通信进行自动化的 mTLS 双向认证和加密，实现东西向流量的安全。二、通过 Spring Cloud Gateway 作为统一的 API 网关，通过 API 网关对南北向流量实施严格的认证、鉴权、速度限制和防重放攻击。三、全站启用 HTTPS，对终端用户到网关、网关到服务的所有外部请求进行加密。

访问与控制安全，采用如下措施：一、身份认证与授权，采用 OAuth2.0 的统一身份认证系统，所有用户通过中央 IDP 登录，实现单点登录。二、细粒度权限控制，在业务微服务层实现基于角色的访问控制，精确管理用户对论文、解析结果、分析功能等的访问权限。三、服务账户管理，为 K8s 中的每个微服务分配独立的 Service Account，并通过 Istio 控制其访问权限，实现最小权限原则。

应用安全，采用如下措施：一、在编码阶段引入代码安全扫描工具比如 SonarQube，在 CI/CD 流水线中集成依赖项漏洞扫描，将安全问题提前发现。二、输入验证和输出编码，在所有微服务接口层面，对用户输入进行严格的校验和清理，并对输出到前端的数据进行编码，防止 XSS 等攻击。三、使用会话令牌，用户会话令牌仅在短期有效，并存储在 Cookie 中，防止 XSS 窃取，且敏感操作比如下载文献等需要进行二次确认。

数据安全，采用如下措施：一、数据分类和加密，对存储的数据进行分类，用户密码经过加盐哈希处理；ElasticSearch 中的论文数据和 PostgreSQL 中的个人数据实施静态加密；对象存储中的 PDF 文件默认启用服务端加密。二、数据脱敏，在日志和分析中，对用户个人信息进行脱敏处理。所有关键操作（登录、下载、删除）均记录详尽的审计日志，并接入 ELK 平台。三、数据备份与恢复，制定并定期测试数据恢复预案。PostgreSQL 数据库进行定期逻辑备份和时间点恢复，ElasticSearch 索引制作快照并保存至对象存储中。

得益于云原生的零信任原则，该项目将安全贯彻整个项目生命周期，通过基础设施安全、网络安全、访问与控制安全、应用安全和数据安全 5 个核心要素，我们在各个环节都制定相应的规则和措施，保障了整个项目的架构安全。经过两年生产环境验证，该安全架构展现出显著成效，系统成功抵御了多次网络攻击尝试，未发生数据泄露事故，细粒度权限控制有效防止了权限滥用，保障了各用户数据的隔离性，基于零信任的网络策略将内部横向移动风险降至最低，平台处理了超过百万篇论文解析请求，保持了 99.95%的服务可用性，安全审计日志为运维决策提供了强力支撑。

在为期两年的生产运维中，我们深刻意识到系统安全是深入架构设计之中的，每次遇到恶意攻击我们都会庆幸已经提前做好了防范措施，系统安全的投入并不是“保险”而是“防火墙”，将危险消除在事故之前而非事后补救才是系统安全的意义所在。虽然目前的系统安全架构设计已经比较完善，但是技术无限发展，当前的项目也存在一些潜在的安全隐患，比如目前针对 AI 的数据投毒等攻击还没有比较好的防御方法，未来我们会持续关注相关技术发展，并跟上时代步伐，安全防范措施总是跟着攻击手段一起进步的，这是必须的也是必然的。
